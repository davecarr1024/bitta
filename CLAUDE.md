# Bitta

Event-driven digital circuit simulator. Logic emerges from primitive interactions — no special-casing for gates, latches, or any higher construct.

**MVP:** a working D flip-flop built from NAND gates built from switches.

## Language and Tooling

Python. Use dataclasses, type hints, and enums throughout. No third-party simulation libraries — everything is from scratch by design.

```
python >= 3.11
pytest             # tests
```

No framework, no ORM, no async. The event queue uses `heapq`. That's the most complex dependency.

## Key Invariants (never violate these)

1. Only nodes hold state — no other object has memory of signal values
2. All influence on nodes is via `set_driver` / `remove_driver` — never mutate `node.current_state` directly
3. Events may only schedule new events at `time >= now` — no past-affecting events
4. Contracts read traces only — they never call anything on `Circuit` or `Node`
5. All circuit construction happens before `Simulator.run()` — no structural changes during simulation

## Code Conventions

- No comments unless the WHY is non-obvious (a hidden constraint, a workaround)
- No docstrings on methods whose name and types are self-explanatory
- `source_id` strings on `DriveIntent` should be stable and human-readable for debugging (e.g. `"vcc:node_42"`, `"switch_7"`, `"conn_3:node_12"`)
- Node IDs generated by `new_id()` — use UUIDs or a global counter, consistently
- Default `inertia_delay=1` for all nodes unless there's a specific reason for another value
- Default `propagation_delay=1` for all connections

## Testing Conventions

Every component definition has a corresponding test that:
1. Builds a minimal circuit (just that component + signal sources)
2. Runs the simulation to quiescence
3. Checks behavior via trace queries (not by inspecting node internals)
4. Uses a contract to express correctness

Tests check behavior through the same interface contracts use. No reaching into `node.drivers` in test assertions — use `state_at(trace, t)` instead.

```python
# example test shape
def test_nand_gate():
    circuit = Circuit()
    a = circuit.add_node()
    b = circuit.add_node()
    y = circuit.add_node()
    nand_gate(circuit, {"A": a, "B": b, "Y": y})

    # drive both inputs HIGH
    circuit.sources.append(ScheduledSource("a", a, [
        (0, DriveIntent("a", Signal.HIGH, Strength.STRONG))
    ]))
    circuit.sources.append(ScheduledSource("b", b, [
        (0, DriveIntent("b", Signal.HIGH, Strength.STRONG))
    ]))

    result = run(circuit, SimulationConfig(time_limit=20))

    y_trace = result.traces.trace(y)
    assert state_at(y_trace, 15) == Signal.LOW
```
